# Звук и голос

В игре две независимые звуковые системы, обе без единого файла на диске:

- **`core/audio.js`** — игровые звуки и музыка, синтезируются через Web Audio API
- **`core/speech.js`** — голосовая озвучка подписей через Web Speech API

Обе выключаются одной кнопкой 🔊 в углу экрана.

## Игровые звуки — `core/audio.js`

### Два кирпичика

Всё построено на двух низкоуровневых методах:

```js
tone({ freq, endFreq, duration, type, volume, delay })  // нота с огибающей
noise({ duration, volume, delay })                      // шумовой всплеск
```

`tone` создаёт осциллятор с экспоненциальным затуханием; если задан `endFreq`,
частота плавно едет к нему — так получаются «поп», «зап» и вой босса.
`noise` заполняет буфер случайными значениями с линейным затуханием — это
шипящая составляющая взрывов.

### Список звуков

| Метод | Где звучит | Как сделан |
|---|---|---|
| `shoot()` | выстрел водяного пистолета | короткий спад частоты, тихий |
| `pop()` | зомби лопнул | восходящая синусоида + шум; высота случайная, чтобы толпа не звучала однообразно |
| `boom()` | взрыв помидора и ракеты | низкая пила + шум |
| `zap()` | молния | резкий спад с 1400 Гц |
| `medal()` / `money()` | подобрал медальку / доллар | две ноты вверх |
| `levelUp()` | новый уровень | восходящее арпеджио из четырёх нот |
| `hurt()` | герою досталось | низкий короткий спад, намеренно нестрашный |
| `flame()` | струя огнемёта | шум + низкая пила |
| `freeze()` | ледяной выстрел | высокий нисходящий «дзинь» |
| `slash()` | взмах светового меча | короткий восходящий свист |
| `bossAppear()` | выход босса | очень низкий восходящий вой в два голоса |
| `abilityReady()` | шкала суперспособности наполнилась | три ноты вверх, тише и короче `levelUp()` — это подсказка, а не праздник, и путать их нельзя |
| `abilityUse()` | способность сработала | спад пилы + шум, общий «вжух» для всех героев |
| `bite()` | собачка тяпнула зомби | короткий спад + шум |
| `beam()` | включился лазерный луч | пила 220→900 Гц; играет **только на включении**, иначе тик раз в 0.22 сек превратится в пулемёт |
| `buzz()` | вылетел рой пчёл | две пилы 90→140 Гц вразнобой — биение даёт жужжание |
| `bonesCollapse()` / `bonesRise()` | костяной рассыпался и собрался | те же четыре ноты вниз и вверх |
| `splat()` | торт клоуна шлёпнулся | шум плюс низкий спад — шлепок, а не взрыв |
| `whistle()` | свисток охранника | две высокие ноты трелью |
| `evolve()` | оружие выросло на пятой звезде | арпеджио ярче `levelUp()`, но короче победы |
| `special()` | начался особый раунд | три ноты вверх, нейтрально-радостно |
| `victory()` | победа | фанфары из семи нот |
| `fail()` | «Почти получилось!» | три ноты вниз, мягко |

Голосом объявляется и воскрешение костяного — «Он встаёт!». Это исключение из
правила «голос только на боссах и карточках»: событие редкое и должно быть
слышно, даже если ребёнок смотрит в другой угол экрана.

Голосовой строки у способности намеренно нет: голос уже звучит на каждом боссе
и на каждой карточке, а звоночек в бою читается быстрее фразы.

### Музыка

Фоновая мелодия — цикл нот из массива `MELODY`, проигрываемый по таймеру
(`setInterval` с шагом 0.28 сек). Каждый шаг играет ноту и её октаву ниже.
В бою с боссом мелодия переключается на `BOSS_MELODY` — низкую и тревожную;
переключение делает `setBossMode(true)`.

Такой подход намеренно примитивен: тайминг «плывёт» на десятки миллисекунд, но
для детской игры это незаметно, зато код остаётся в двадцать строк.

### Разблокировка

Браузеры не дают создавать `AudioContext` до действия пользователя. Поэтому
`unlock()` вызывается при первом `pointerdown` на странице и повторно при старте
раунда. Пока контекст не создан, все методы звука молча ничего не делают.

Выключение звука не останавливает синтез, а ставит громкость мастер-узла в ноль —
так переключение мгновенное и не ломает уже запущенные ноты.

### Как добавить свой звук

1. Добавьте метод в класс `Audio`, собрав его из `tone()` и `noise()`.
2. Вызовите его оттуда, где происходит событие — обычно это `core/round.js`,
   у которого есть ссылка `this.audio`.

Оружие тоже может звучать: у него есть `world.audio` (см. `WaterGun.fire()`).

## Голосовая озвучка — `core/speech.js`

Ребёнок пяти лет ещё не читает, поэтому **любую подпись в игре можно
послушать голосом**. Говорит сам браузер (`speechSynthesis`), русским системным
голосом — на macOS это обычно Milena. Никаких записанных файлов.

```js
speech.speak('Молния, 3 звезды');  // произносит, прервав предыдущую фразу
speech.stop();                      // замолчать
speech.setEnabled(false);           // выключено вместе с остальным звуком
```

Речь чуть замедлена (`rate 0.95`) и чуть выше по тону (`pitch 1.15`) — так
понятнее и дружелюбнее. Новая фраза всегда прерывает предыдущую: несколько
наложенных голосов ребёнок всё равно не разберёт.

Список голосов в некоторых браузерах приходит асинхронно, поэтому `Speech`
подписывается на событие `voiceschanged` и выбирает русский голос заново.
Если синтеза речи нет вовсе, класс просто молчит — игра работает как прежде.

### Где есть кнопка 🔈

На каждой карточке с подписью: кто играет, выбор сложности, выбор героя, выбор
стартового оружия, карточки прокачки, товары в магазине, наклейки в альбоме
(включая закрытые) и список оружия на паузе. Разметку кнопки даёт
`Overlay.speakButton(text)`, обработчики вешает `bindSpeakButtons(onSpeak)` —
клик по динамику не выбирает карточку, на которой он стоит.

При переключении выбора стрелками название читается автоматически: так ребёнок
понимает, что именно сейчас выбрано, не умея прочитать подпись.

### Объявление боссов

Босс каждый раунд новый, а прочитать его имя ребёнок не может — поэтому при
выходе игра объявляет его голосом: «Осторожно! Мама-зомби!».

Механика проста: `Round.startBossIntro()` зовёт колбэк `onBossAppear(name)`,
а `Game` произносит фразу через `speech`. Имя берётся из
`CONFIG.bossTypes[].name`, так что в коде оно не дублируется.

Тон намеренно «объявление аттракциона», а не угроза: для пятилетнего выход
босса должен быть главным событием раунда, а не поводом испугаться.

### Фразы для голоса

Текст для озвучки строят маленькие функции рядом с каждым экраном
(`describeCard`, `describeCharacter`, `describeItem`, `describeWeapon`).
Они же склоняют слова по числу — «1 звезда», «3 звезды», «5 звёзд»,
«1 доллар», «20 долларов». Это важнее, чем кажется: неправильное склонение
ребёнок замечает сразу и переспрашивает.
