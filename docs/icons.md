# Иконки

Значки интерфейса рисует код, а не шрифт операционной системы.

## Зачем

Эмодзи рисует системный шрифт: на маке одни картинки, на Windows другие
(Segoe UI Emoji), на Linux часть может отсутствовать вовсе. Ребёнок пяти лет
читать не умеет и ориентируется в игре **исключительно по значкам** — значит
на чужом компьютере игра для него выглядит иначе, а местами ломается.

Заодно снимается лицензионный вопрос: рисунки эмодзи Apple защищены авторским
правом, копировать их нельзя. Мы рисуем те же **предметы** своей рукой.

Граница честная: одинаковыми стали **значки, а не буквы**. Шрифт остался
системным — текста в игре мало и он для взрослого.

## Граница ответственности

**Персонаж — canvas, значок — SVG.**

Герои, зомби и боссы всюду рисуются тем же кодом, что и в бою
([sprites.js](../js/render/sprites.js)) через `Overlay.paintHero` и соседей.
Переводить их на иконки нельзя: в этом весь смысл альбома — наклейка должна
быть тем же существом, что бегало по экрану.

Но зомби в счётчике HUD и в шапке альбома — это **подпись**, а не портрет.
Для них есть отдельный маленький `ui-zombie`: настоящий `drawZombie` на
двадцати пикселях превращается в зелёное пятно.

## Устройство

```
js/render/icons.js            фасад: icon(), drawIcon(), ICON_NAMES
js/render/icons/palette.js    именованные цвета
js/render/icons/shapes.js     геометрия: круг, звезда, капля, молния…
js/render/icons/registry.js   сводит домены в один объект ICONS
js/render/icons/ui.js         интерфейс — кнопки, состояния, счётчики
js/render/icons/weapons.js    оружия и эволюции
js/render/icons/abilities.js  суперспособности
js/render/icons/awards.js     магазин, медали, сложности
js/render/icons/places.js     локации и особые раунды
```

### Одно определение, две отрисовки

Значки нужны в двух несовместимых местах: в разметке экранов (её собирают
шаблонными строками через `setContent`) и на игровом canvas (HUD).

```js
icon('ui-shop')                        // → строка <svg>, прямо в шаблон
drawIcon(ctx, 'ui-medal', x, y, 14)    // → на canvas, центр в (x, y)
```

Разойтись они не могут **по устройству**: обе берут одну и ту же строку пути.
Круг в `shapes.js` — тоже путь, а не `ctx.arc` и не `<circle>`. Расхождение
двух рендереров было бы самым вероятным классом ошибок в этой задаче, и он
закрыт устройством, а не внимательностью.

### Размер в em

`icon()` по умолчанию не ставит ни `width`, ни `height` — их даёт правило
`.icon { width: 1.15em; height: 1.15em }`. Поэтому все прежние правила вида
`.card__emoji { font-size: 60px }` продолжают работать без единой правки,
включая оба медиазапроса и посчитанную вручную раскладку выбора героя под
375 пикселей.

Коэффициент 1.15 — один на весь проект. По классам его подгонять нельзя,
иначе набор разъедется.

Что пришлось поправить — только `line-height`: он был подогнан под метрику
эмодзи (у глифа свой воздух сверху и снизу) и после замены просто добавлял
пустоту в карточку.

### Ни DOM, ни Path2D при импорте

Реестр обязан подниматься в Node: [test/no-emoji.mjs](../test/no-emoji.mjs)
сверяет с ним имена иконок из конфига. `Path2D` существует только в браузере,
поэтому строится лениво, при первой отрисовке, и кешируется — HUD рисует
значки шестьдесят раз в секунду, разбирать строку пути каждый кадр незачем.

## Как добавить иконку

1. Выберите домен и добавьте запись в соответствующий файл `icons/`:

```js
'ui-key': [
  { d: rect(10, 14, 12, 12, 3), fill: 'gold' },
  { d: disc(16, 10, 5), stroke: 'goldDark', width: 3 },
],
```

Часть — это `d` (строка пути) плюс `fill`, `stroke`, `width`, `alpha`, `cap`.
Цвета — **имена из палитры**, не коды: сто иконок иначе расползутся на
шестьдесят оттенков.

2. Откройте [стенд значков](../preview.html#icons) и посмотрите на неё
   **на размере 16** — это слот оружия в HUD. Там ломается всё.
3. Переключите фон на светлый и на все семь грунтов локаций.
4. Сравните колонку «canvas» с левой половиной карточки: формы обязаны
   совпасть.

Неизвестное имя не молчит: `icon()` вернёт красный квадрат с вопросом и один
раз напишет в консоль. Плюс `npm test` сверяет имена из конфига с реестром.

## Чему научил стенд

Список правок после просмотра — он же список ловушек:

| Значок | Что было не так |
|---|---|
| бумеранг | залитая фигура с изогнутыми боками на 16px читалась как клякса — стал толстым уголком **обводкой** |
| морковка | остриём вверх и с зеленью снизу — вылитая ёлка |
| снежинка | шесть лучей сливаются в пятно, оставили три с засечками |
| паучок | чёрный на тёмной панели меню исчезал целиком |
| кулак «Ярости» | вид сбоку читался как круассан |
| рюкзак | без лямок и кармана — надгробие |
| «Против толпы» | четыре круга выглядели клевером: голову зомби делает угловатость и глаза |
| рукопожатие | на 16px — две стрелки навстречу |
| сноп фермы | читался как корона, а корона занята боссом |
| собака | уши торчком делали из неё кота |
| бицепс | после двух попыток так и остался картошкой — заменили на звёзды |

Общее правило из этого списка: **на шестнадцати пикселях работает силуэт, а
не детали.** Если фигуру нельзя узнать по контуру — её не спасут ни цвет, ни
блики.

Второе: у оружия **эволюция намеренно делит силуэт с родителем** и отличается
цветом или добавкой. Различимых силуэтов остаётся пятнадцать вместо двадцати
девяти — двадцать девять на таком размере просто не бывает.

## Проверка

`npm test` начинается с [no-emoji.mjs](../test/no-emoji.mjs) — он занимает
миллисекунды, а смоук полминуты. Две проверки:

1. **эмодзи в выводимом коде** (`js/`, `css/`, `index.html`, стенды).
   Комментарии вырезаются: там эмодзи помечают разделы, их больше сотни и они
   полезны. `docs/` и `README.md` не проверяются вовсе;
2. **имена иконок из конфига** существуют в реестре.

Диапазон шире, чем «эмодзи»: `▶` (U+25B6) и `●` (U+25CF) живут в блоке
геометрических фигур, и без него проверка пропустила бы половину кнопок.

Проверка нашла семнадцать пропусков, которых не увидел глаз, — в том числе
значок на экране паузы. Такое глазами не ловится в принципе: здесь, на маке,
забытый эмодзи выглядит прекрасно.

**Главная проверка задачи делается руками:** открыть игру в двух браузерах с
разными движками (Chrome и Safari) — значки обязаны совпасть.
