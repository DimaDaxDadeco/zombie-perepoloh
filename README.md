# 🧟 Зомби-переполох

Браузерная игра для ребёнка 5 лет: супергерой бегает по арене, оружие стреляет
само, зомби лопаются конфетти, а в конце раунда выходит босс в цилиндре.

Героев десять — Супер-мэн, Супер-Егор, Робот, Котик, Соник, Человек-паук,
Халк, Пикачу, Мистер Хэнки и Бэтмен, у каждого свой небольшой бонус и своя
суперспособность. Стартовое оружие тоже выбирается: их четырнадцать, включая
огнемёт, ледяную пушку, световой меч, лазерные глаза, огненную дорожку и
торнадо, и каждое на пятой звезде превращается во что-то новое. Зомби семнадцати видов — от шустриков и
толстяков до зомби-собак, шариков, тыкв, снеговиков, ниндзя и каменного
голема. Боссов двенадцать, с первого по двенадцатый раунд каждый выходит
впервые, дальше они приходят в случайном порядке, и игра объявляет каждого
голосом.

Есть **сюжетный режим** — два путешествия по двенадцать глав, каждое со своей
картой. В первом зомби утащили альбом наклеек и разнесли страницы по локациям;
каждая пройденная глава возвращает страницу. Второе открывается финалом первого:
зомби заперли друзей в клетках по всему свету.

У глав разные задачи, и все они про движение — единственное, что ребёнок умеет:
победить босса, продержаться, прогнать столько-то зомби, собрать медальки,
освободить друзей из клеток, догнать воришку, уберечь костёр или отнести ношу
на место. Прогресс виден на карте.

Ребёнок ещё не читает, поэтому **любую подпись можно послушать голосом** —
кнопка 🔈 есть на каждой карточке.

**Управление — стрелки** (или WASD) и **пробел**. У каждого героя своя
суперспособность: она копится за убитых зомби, а когда шкала полна — герой
обрастает звёздочками, звенит звоночек, и пробел пускает её в ход.

## Играть

**<https://dimadaxdadeco.github.io/zombie-perepoloh/>** — открывается на
компьютере, планшете и телефоне, ничего устанавливать не надо.

## Как запустить локально

Двойной клик по **`start.command`** — откроется браузер с игрой.

Если macOS ругается на неизвестного разработчика: правый клик по файлу → «Открыть».

Вручную то же самое:

```bash
cd ~/Desktop/Game && python3 -m http.server 8321
```

На планшете — открыть тот же адрес, подставив IP компьютера в локальной сети:
управление переключится на джойстик под пальцем автоматически.

Затем открыть <http://localhost:8321>. Локальный сервер нужен потому, что браузеры
не загружают ES-модули по протоколу `file://`.

## Как играть

| Действие | Клавиши |
|---|---|
| Бегать | ← ↑ → ↓ или WASD, стик геймпада |
| Суперспособность | Пробел или A на геймпаде (когда шкала полна и вокруг героя вьются звёздочки) |
| Выбрать сложность, героя, оружие или карточку | ← → и Enter (или мышкой) |
| Послушать название голосом | кнопка 🔈 на карточке |
| Пауза | Esc, Start на геймпаде или кнопка ⏸ |
| Звук вкл/выкл | кнопка 🔊 в правом верхнем углу |

Раунд длится две минуты, потом появляется босс. Победа над боссом завершает раунд.
Проигрыша нет: если сердечки кончились, герой просто отряхивается и можно повторить.

Можно играть **вдвоём на одном экране**: второй герой на WASD или на
геймпаде, у каждого свои сердечки, оружие и суперспособность. Падение одного не
заканчивает раунд — напарник поднимет.

Каждый четвёртый раунд особый: дождь медалек, ночь с фонариком или волна-толпа.
В магазине можно купить **собачку и робота-помощника**, а прокачав оружие до
пятой звезды — получить его **улучшенную версию**. Всех встреченных зомби и
побеждённых боссов собирает **альбом наклеек**.

**Три уровня сложности** — 🐣 Легко (тот самый детский баланс), 🙂 Нормально и
🔥 Сложно. Уровень выбирается один раз, в начале новой игры, и за сложность
платят больше долларов.

В меню две кнопки: **«Продолжить»** возвращает в сохранённый раунд, **«Новая
игра»** начинает с нуля и заново предлагает выбрать героя и оружие. Новая игра
спрашивает подтверждение, так что случайно стереть прогресс не выйдет.

## Как обновить игру в интернете

```bash
git add -A && git commit -m "что поменялось" && git push
```

Через минуту изменения на боевом адресе: `git push` запускает workflow
[.github/workflows/pages.yml](.github/workflows/pages.yml), который
выкладывает папку как есть. Сборки нет — игра это статика без зависимостей.

Ход деплоя видно во вкладке **Actions** на GitHub.

## Стенды для рисовки

Все стенды — на одной странице `preview.html`, вкладками: герои, зомби,
боссы, локации, значки и огненная дорожка. Открывается на том же сервере, что
и игра. Страница импортирует настоящий код, так что персонажи и значки там
ровно те же, что в бою; активная вкладка живёт в адресе
(`preview.html#zombies`), поэтому после правки спрайта обновление возвращает
туда же, где смотрел. Подробности — в
[docs/contributing.md](docs/contributing.md).

## Технологии

Ванильный JavaScript (ES-модули), Canvas 2D, Web Audio API.
Ни одной внешней зависимости, ни одного графического или звукового файла —
персонажи рисуются кодом, звуки синтезируются на лету. Работает без интернета.
